# Yeonrak (연락)

**Website: https://kimmireu0921.github.io/Innovation-and-Corporate-Transformation/**

Yeonrak is the opt-in call exchange: verify once, say when and why, and only ever take the calls you asked for. It lives inside the apps people already use, so there is nothing new to download.

This is an ongoing class project for **Innovation and Corporate Transformation** at Yonsei GSIS with Prof. Chung Yunho (Fall 2026, Team 2). We are building the strategy step by step using the *Playing to Win* framework.
